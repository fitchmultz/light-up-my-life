How it works

Light Up My Life saves each EDR-capable display's gamma tables, activates Extended Dynamic Range with a tiny Metal HDR window, then scales the saved tables to brighten desktop content. No full-screen overlay or multiply filter.

1

Save Gamma

Capture the display's current RGB gamma tables

2

Tiny HDR Seed

A 5×5-point click-through window in the corner

3

HDR Rendering

Display P3 PQ and floating-point color values above 1.0

4

Gamma Boost

Scale the saved tables to brighten desktop content

Turning boost off or quitting normally restores the saved gamma tables. Wake and display changes rebuild the HDR windows and reapply the boost; a three-second watchdog re-shows existing hidden windows without rebuilding them. The seed windows can appear in screenshots or screen recordings — read-only window sharing does not exclude them from capture.
